**MediAI** is an intelligent decision-support platform for breast cancer diagnosis, built on a modular multi-agent architecture. It combines fine-tuned vision models, a medical Retrieval-Augmented Generation (RAG) mechanism, and a large language model to generate structured and interpretable clinical reports from mammograms.

## ✨ Features

- 🔍 **Automatic lesion detection** using YOLO11m fine-tuned on the DMID dataset.
- 🏷️ **Three-class classification** (Normal, Benign, Malignant) using a Swin Transformer.
- 📐 **Morphological metrics extraction**, including lesion size, area, perimeter, and circularity.
- 📚 **Contextual retrieval (RAG)** using Qdrant, BGE-M3 embeddings, and NCCN/AGO clinical guidelines.
- 🧠 **Structured clinical reasoning** generated by Qwen2.5-7B through Ollama.
- 📊 **Automatic BI-RADS assignment** based on the malignancy score.
- 🖼️ **Annotated image generation** with visual indicators for detected lesions.
- 📄 **Structured clinical reports** exportable to PDF.
- 💬 **Conversational assistant** for querying generated reports.
- ⚡ **Real-time progress tracking** through WebSockets.
- 🎨 **React web interface** featuring a dashboard, analysis history, and statistics.

## 🏗️ Architecture

MediAI uses a multi-agent architecture orchestrated by **LangGraph**. The pipeline processes mammograms, retrieves relevant medical knowledge, generates clinical reasoning, and produces structured reports.

```text
┌─────────────────┐
│   PNG Image     │
│   Mammogram     │
└────────┬────────┘
         │
         ▼
┌─────────────────────────────────────────────┐
│           Orchestrator (LangGraph)           │
└────────┬────────────────────────────────────┘
         │
         ├──► Vision Agent
         │    └── YOLO + Swin Transformer
         │
         ├──► RAG Agent
         │    └── Qdrant + BGE-M3
         │
         ├──► Reasoning Agent
         │    └── Qwen2.5-7B
         │
         └──► Report Agent
              └── Report structuring and image annotation
         │
         ▼
┌───────────────────────┐
│    Clinical Report    │
│    Markdown + PDF     │
└───────────────────────┘
```

### Architecture Layers

- **Frontend:** React 18, TypeScript, and Tailwind CSS.
- **API Gateway:** FastAPI and Uvicorn, providing REST endpoints and WebSocket communication.
- **Orchestrator:** LangGraph for workflow orchestration and shared state management.
- **AI Agents:** Vision, RAG, reasoning, and report generation.
- **Services:** PostgreSQL for persistence, Qdrant for vector storage, and Ollama for local LLM inference.

## 🚀 Installation

### Prerequisites

- Python 3.12+
- Node.js 18+
- Docker and Docker Compose
- A CUDA-compatible GPU (approximately 8 GB of VRAM recommended)
- [Ollama](https://ollama.com/) installed and running

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/MediAI.git
cd MediAI
```

Replace `YOUR_USERNAME` with your GitHub username and ensure the repository URL matches your actual repository.

### 2. Download the Fine-Tuned Models

The fine-tuned model weights, `yolo_breast.pt` and `swin_breast_3class.pth`, are not included in the repository because of their size.

Place the model files in:

```text
backend/app/ml/models/
```

### 3. Pull the LLM Using Ollama

```bash
ollama pull qwen2.5:7b-instruct
```

### 4. Start the Services

```bash
docker compose up -d
```

This command starts the services defined in your Docker Compose configuration, such as PostgreSQL, Qdrant, and Ollama, if configured.

### 5. Install Backend Dependencies

```bash
cd backend
python -m venv .venv
```

Activate the virtual environment.

**Linux/macOS:**

```bash
source .venv/bin/activate
```

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

### 6. Configure Environment Variables

```bash
cp .env.example .env
```

On Windows, copy the file using:

```powershell
Copy-Item .env.example .env
```

Edit the `.env` file and configure the required database credentials, service URLs, model settings, and other environment variables.

### 7. Launch the Backend

From the `backend` directory, run:

```bash
uvicorn app.main:app --reload --port 8001
```

### 8. Launch the Frontend

Open another terminal and navigate to the frontend directory:

```bash
cd frontend
npm install
npm run dev
```

The application will typically be available at:

http://localhost:5173

The actual URL depends on your Vite configuration.

## 🎯 Usage

### Via the Web Interface

1. Open the frontend URL in your browser.
2. Navigate to the **Upload** section.
3. Upload a mammogram in PNG format and provide the required clinical data.
4. Track the analysis progress in real time.
5. Review the generated report, annotated images, and classification results.
6. Export the report to PDF or interact with the conversational assistant.

### Via the API

Submit a diagnostic request using the following example:

```bash
curl -X POST http://localhost:8001/api/v1/diagnosis \
  -F "patient_id=P-12345" \
  -F "age=55" \
  -F "mammo_file=@/path/to/mammogram.png"
```

The response is expected to contain a `task_id` that can be used to track the analysis, depending on the implemented API response schema.

Check the analysis status:

```bash
curl http://localhost:8001/api/v1/diagnosis/{task_id}/status
```

Retrieve the result:

```bash
curl http://localhost:8001/api/v1/diagnosis/{task_id}/result
```

Replace `{task_id}` with the identifier returned by the initial request.
